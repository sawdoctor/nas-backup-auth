Sawdoctor NAS Backups

A personal backup utility operated by Sawdoctor. It uses rclone to store, verify and recover the owner's backup files in the owner's Google Drive account.

Google Drive access

The owner authorises access using Google OAuth. The utility lists backup files, uploads new backups, checks their integrity, downloads files for recovery and removes old backup versions according to the owner's retention settings.

This website provides information about that utility. It does not offer Google sign-in, accept uploads or provide a public backup service.
